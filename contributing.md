# Contributing to TBU Framework

Thank you for your interest in contributing to the Topological Boundary Unit (TBU) Framework!

## Development Workflow
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/HigherOrderExtension`).
3. Ensure your code leverages PyTorch CUDA tensors where applicable to maintain the 60+ FPS performance standard.
4. Commit your changes (`git commit -m 'Add support for higher-order multipoles'`).
5. Push to the branch (`git push origin feature/HigherOrderExtension`).
6. Open a Pull Request for review.
