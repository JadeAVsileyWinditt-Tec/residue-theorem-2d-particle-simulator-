# Residue Theorem 2D Particle Simulator

**Enhanced 2D Complex Physics Engine**  
Integrating Rational Functions, Complex Numbers & Contour Integration

An interactive laboratory that turns complex analysis into living physics.  
Positions and velocities live as complex numbers. Forces are generated by rational functions (simple poles). Net impulse follows the residue theorem. A potential-flow mode lets particles become tracers of classic analytic flows.

---

## Executive Summary

This project upgrades a conventional 2D particle simulator (gravity, elastic collisions, mouse interaction) into a mathematically rigorous engine built on complex analysis:

- Full complex-number representation for position and velocity
- Rational force fields generated by interactive, draggable poles
- Potential-flow visualiser driven by analytic complex potentials
- Direct theoretical link to contour integration and the residue theorem

The result is an exploratory tool where the mathematics of the complex plane is the physics engine.

---

## Core Features

### 1. Complex Number Foundation
- Position z and velocity v stored as complex numbers
- Rotation, oscillation and scaling become simple multiplications by e^{iθ} or e^{iωt}
- Euler integration collapses to the elegant form:  
  z += v * DT
- Cleaner code for vector arithmetic, normalisation and central forces

### 2. Rational Force Field System
Forces are generated by a rational function of isolated poles:

F(z) = Σ strength_k / (z - pole_k)

- Real part of strength → source / sink (repulsive or attractive)
- Imaginary part of strength → vortex (circulatory force)
- Poles are fully interactive: add, delete and drag with the mouse while the simulation runs
- Superposition of multiple poles creates rich, non-central force landscapes

### 3. Potential Flow Visualiser Mode
Press V to switch into potential-flow mode. Particles become passive tracers following an analytic velocity field derived from a complex potential w(z) = φ + iψ.

Default flow: uniform flow past a circular cylinder

f(z) = U (z + R²/z)

This classic textbook example automatically satisfies the no-penetration condition on the cylinder surface thanks to analyticity.

### 4. Residue Theorem Connection
Because the force field is a rational function (sum of simple poles), the net circulation / impulse delivered to a particle travelling around a closed path is exactly 2πi times the sum of enclosed residues. The simulator makes this discrete analogue of contour integration visible and interactive.
